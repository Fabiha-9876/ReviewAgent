# Stage-4 response files, and which ones are superseded

This folder contains two generations of Stage-4 response data. The difference between them is
the reason the paper's headline downstream claim changed, so read this before using anything
here.

## Superseded, kept for the record

| file | what it is |
|---|---|
| `responses_reviewagent_full.json` | produced by `scripts/generate_reviewagent_full.py` |
| `responses_reviewagent_no_spec.json` | produced by `scripts/generate_reviewagent_no_spec.py` |
| `responses_prompt_baseline.json` | produced by `scripts/generate_prompt_baseline.py` |
| `responses_rrgen_baseline.json` | template baseline, not an RRGen model checkpoint |

These four were **not generated by a language model**. Each comes from a deterministic template
composer with a hand-written sentence bank. The composers also differ in writing register: the
`no_spec` file averages 78 words in lemmatised, ungrammatical English, while the `full` file
averages 123 words of polished prose and receives cleanup passes and an empathy phrasebook that
the other arms do not.

Ratings collected on these files therefore compare two writing styles as much as they compare
the presence of an IssueSpec. The +2.35 Likert gain measured on them is withdrawn.

## Current

| file | what it is |
|---|---|
| `responses_reviewagent_full_LLM.json` | same model, same retrieved context, IssueSpec in the prompt |
| `responses_reviewagent_no_spec_LLM.json` | same model, same retrieved context, no IssueSpec |

These two differ in exactly one respect. They average 105 and 97 words with distinct-1 of 0.736
and 0.760, so a rater cannot separate them on surface features. The reported result comes from
these, rated by three people across all 200 blinded rows:

    pooled gain +0.04 Likert, 95% CI [-0.10, +0.18], paired Wilcoxon p = 0.38

Reproduce with `python3 scripts/run_stage4_llm_rerun.py`, which also runs the independence check
on the three rating sheets.

## If you are building on this

Use the `_LLM` files. If you want to reproduce the withdrawn number for comparison, the old
files are here and the old ratings are in `human_work/response_ratings.xlsx`, but do not report
that number as a measurement of the IssueSpec's effect.
