# Response Rating Task - README

You have one file, `response_ratings_D.xlsx` or `response_ratings_E.xlsx`. Fabiha will tell
you which is yours.

100 app reviews, 4 candidate replies each, 400 rows. Fill three columns per row: quality
(1-5), specificity (1-5), and helpful (Y/N). The Instructions sheet inside the file has the
scale definitions and the guidance, read it first.

The reply labels A/B/C/D are shuffled per review, so the same letter is a different system on
different rows. Do not try to work out which system is which, and do not discuss individual
rows with the other rater while the round is open.

About 2 hours. Save as you go. Send the file back under its original name.
